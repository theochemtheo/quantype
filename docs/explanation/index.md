# Concepts

[The physical model](physical-model.md) explains why quantype separates nominal
kinds from dimensions, how declared relations name products, and why presentation
units do not control numerical storage. Read it when a dimensionally plausible
operation is rejected or you need to choose a numerical boundary.

Use the [glossary](glossary.md) for a short definition of a linked term.

This is the current user-facing model, not decision history. Exact APIs live in
[Reference](../reference/index.md); historical rationale lives in
[accepted decisions](https://github.com/theochemtheo/quantype/tree/main/docs/decisions), within contributor guidance.
